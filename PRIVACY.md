## Español

### Alcance

Este aviso describe la página web BloomBox iOS Installer. No describe las aplicaciones instaladas ni los servicios externos. El proyecto está identificado en GitHub como AdriFOG/Bloombox-iOS-Installer.

### Datos guardados en tu dispositivo

El navegador guarda localmente idioma, apariencia, aplicación elegida, avance, confirmaciones, referencia a la IPA seleccionada y la versión y fecha de aceptación de los términos. Se usan para recordar tus preferencias y continuar el asistente. No se envían al proyecto mediante un formulario o servidor propio. La aceptación local no constituye un registro de identidad ni una prueba independiente de aceptación.

### Hosting y conexiones

El sitio se aloja en GitHub Pages y consulta la API pública de GitHub para obtener versiones. GitHub puede tratar datos técnicos, como IP y solicitudes HTTP, conforme a su propia política. La web no incorpora herramientas de analítica o publicidad del proyecto. Los enlaces externos, App Store, Open Minis, LocalDevVPN, siboot, Apple y servicios de anisette están sujetos a sus propias políticas. Al abrirlos o ejecutar el comando pueden realizar conexiones y solicitar datos fuera de esta web.

### Credenciales y emparejamiento

La web no solicita ni tiene acceso a tu correo de Apple, contraseña, códigos de verificación, certificados, claves privadas o archivos de emparejamiento. No los compartas en GitHub Issues ni con el proyecto. La copia de comandos usa el portapapeles del dispositivo cuando tú pulsas el botón correspondiente.

### Control y conservación

Los datos locales permanecen hasta que los borres, el navegador los elimine o se sustituyan. Puedes utilizar Borrar avance guardado para eliminar el progreso y la aceptación, o borrar los datos del sitio en Safari para eliminar también las preferencias de apariencia. No hay una cuenta web asociada a estos datos. Si tienes preguntas de privacidad o quieres ejercer derechos aplicables, usa los canales de contacto del repositorio sin publicar datos sensibles. Para datos tratados por un tercero, consulta su política y sus canales de privacidad.

### Actualizaciones

Publicaremos cambios a este aviso con una nueva fecha o versión. Consulta los documentos del repositorio para conocer el texto vigente.

## English

### Scope

This notice describes the BloomBox iOS Installer website. It does not describe installed apps or external services. The project is identified on GitHub as AdriFOG/Bloombox-iOS-Installer.

### Data stored on your device

Your browser stores language, appearance, selected app, progress, confirmations, the selected IPA reference and terms acceptance version and date locally. These are used to remember preferences and resume the assistant. They are not sent to the project through a form or project-operated server. Local acceptance is not an identity record or independent proof of acceptance.

### Hosting and connections

The site is hosted on GitHub Pages and queries GitHub's public API for releases. GitHub may process technical data such as IP addresses and HTTP requests under its own policy. The site has no project-operated analytics or advertising tools. External links, App Store, Open Minis, LocalDevVPN, siboot, Apple and anisette services have their own policies. Opening them or running the command may create connections and request data outside this website.

### Credentials and pairing

The website does not request or have access to your Apple email, password, verification codes, certificates, private keys or pairing files. Do not share them in GitHub Issues or with the project. Copying commands uses the device clipboard when you press the relevant button.

### Control and retention

Local data remains until you delete it, the browser removes it or it is overwritten. Use Clear saved progress to remove progress and acceptance, or clear Safari website data to also remove appearance preferences. No website account is associated with this data. For privacy questions or applicable rights requests, use the repository contact channels without posting sensitive data. For data processed by third parties, consult their policies and privacy channels.

### Updates

Changes to this notice will be published with a new date or version. See the repository documents for the current text.
